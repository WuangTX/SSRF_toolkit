🟢 Whitebox SSRF Testing

← Về Dashboard
💡 Whitebox Mode: Phân tích source code hoặc API spec để tự động sinh SSRF checklist. Độ chính xác cao nhất, false positive thấp nhất.

✨ Whitebox Mode có thể:

  • Phân tích source code tìm HTTP client calls (requests, urllib, axios, fetch)
  • Detect URL parameters có thể bị SSRF
  • Parse Swagger/OpenAPI để tạo full endpoint list
  • Tự động sinh SSRF test cases từ route definitions
  • Scan routers và HTTP clients trong codebase

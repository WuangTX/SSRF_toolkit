💡 Hướng dẫn sử dụng

1. Chọn Test Mode phù hợp:

  • Blackbox: Khi bạn chỉ có URL công khai, không có quyền truy cập nội bộ
  • Graybox: Khi bạn có auth token hoặc có quyền truy cập vào K8s/Consul/Docker
  • Whitebox: Khi bạn có source code hoặc API specification

2. Cấu hình Safe Mode:

  • Luôn bật Safe Mode khi scan production environment
  • Sử dụng Scope Protection để giới hạn phạm vi scan
  • Throttle RPS để tránh gây quá tải target

3. Chọn Attack Depth:

  • Quick: Scan nhanh với payload cơ bản (5-10 phút)
  • Deep: Scan sâu với 500+ signatures (20-40 phút)
  • Cloud: Chuyên biệt cho AWS/GCP/Azure metadata
  • Container: Targeting Docker/K8s/Consul services

4. Xem kết quả:

  • Real-time monitoring qua trang Results
  • Export report dưới dạng JSON/HTML
  • Chi tiết findings bao gồm PoC và remediation

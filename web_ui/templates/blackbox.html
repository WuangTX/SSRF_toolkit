💡 HAR/Burp file là gì?
• File chứa NHIỀU requests/responses khi browse website
• Cách tạo HAR: Chrome DevTools → Network → Right-click → "Save all as HAR"
• Cách tạo Burp: Burp Suite → Proxy → HTTP History → Select all → Right-click → "Save items"
• Tool sẽ extract tất cả endpoints từ file (có thể 50-200+ endpoints)
• Bao gồm: URLs, headers, cookies, POST data, authentication tokens
